KubeLoop has been installed as three independent workloads:

  Control Plane: {{ include "kubeloop.controlPlaneName" . }}
  Data Plane: {{ include "kubeloop.dataPlaneName" . }}
  Operator: {{ include "kubeloop.operatorName" . }}

{{- if .Values.controlPlane.development.enabled }}
Development mode is enabled. Any authenticated user can access the service.
{{- end }}

Service discovery:
  {{ required "publicURL is required" .Values.publicURL }}/.well-known/kubeloop

{{- if .Values.controlPlane.admin.bootstrap.enabled }}
On a new database, the Control Plane creates the initial administrator
{{ .Values.controlPlane.admin.bootstrap.username | quote }}.
The random initial password is stored in a Kubernetes Secret:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "kubeloop.iamBootstrapSecretName" . }} -o jsonpath='{.data.{{ .Values.controlPlane.admin.bootstrap.passwordKey }}}' | base64 -d; echo
{{- else }}
On a new database, the Control Plane logs one one-time IAM bootstrap token.
It expires after 24 hours and is never stored in plaintext. Use it in the
Management UI to create the first administrator.
{{- end }}
{{- if and (not .Values.ingress.enabled) (not .Values.gatewayAPI.enabled) }}
Start a local tunnel:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kubeloop.controlPlaneManagementName" . }} 8081:{{ .Values.controlPlane.admin.servicePort }}
{{- end }}
Then sign in at:
  {{ required "controlPlane.admin.publicURL is required" .Values.controlPlane.admin.publicURL }}/api/admin/ui

{{- if and (not .Values.ingress.enabled) (not .Values.gatewayAPI.enabled) }}
Chart-managed external routing is disabled. Route the same public origin as follows:
  /.well-known, /oauth2, /kubeloop/api and /api/sessions -> {{ include "kubeloop.controlPlaneName" . }}
  /api/admin -> {{ include "kubeloop.controlPlaneManagementName" . }}
  {{ .Values.dataPlane.tunnelPath }} -> {{ include "kubeloop.dataPlaneName" . }}
{{- end }}
{{- if .Values.ingress.enabled }}
External access, including the Management Plane, uses networking.k8s.io/v1 Ingress for {{ .Values.ingress.host }}.
{{- end }}
{{- if .Values.gatewayAPI.enabled }}
External access, including the Management Plane, uses gateway.networking.k8s.io/v1 HTTPRoute for {{ .Values.gatewayAPI.host }}.
Confirm the Route Accepted/ResolvedRefs conditions and HTTPS listener certificate before login.
{{- end }}

Storage mode: {{ ternary "external datasource" "SQLite" (not (empty .Values.controlPlane.storage.datasource.existingSecret)) }}
{{- if not .Values.controlPlane.storage.datasource.existingSecret }}
SQLite mode intentionally runs one Control Plane replica with Recreate updates.
Configure controlPlane.storage.datasource.existingSecret with a PostgreSQL or MySQL datasource URL for external storage.
{{- end }}
