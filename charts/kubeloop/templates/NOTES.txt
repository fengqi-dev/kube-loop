{{- if .Values.controlPlane.management.initialAdmin.enabled }}
Initial Management Plane administrator:
  Username: kubectl -n {{ .Release.Namespace }} get secret {{ include "kubeloop.initialAdminSecretName" . }} -o jsonpath='{.data.{{ .Values.controlPlane.management.initialAdmin.usernameKey }}}' | base64 -d
  Password: kubectl -n {{ .Release.Namespace }} get secret {{ include "kubeloop.initialAdminSecretName" . }} -o jsonpath='{.data.{{ .Values.controlPlane.management.initialAdmin.passwordKey }}}' | base64 -d

The Secret is only a bootstrap input. Password values are not applied again
after the local administrator exists in Control Plane storage. The Management
Plane is not exposed on the public Control Plane port. Start a local tunnel:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kubeloop.controlPlaneManagementName" . }} 8081:{{ .Values.controlPlane.management.servicePort }}
Then sign in at:
  {{ required "controlPlane.management.publicURL is required" .Values.controlPlane.management.publicURL }}/kubeloop/api/admin/ui
TOTP is optional. A user may enable it from Account Security and must then save
the one-time recovery codes; users who do not enroll continue with password-only login.
{{- end }}
